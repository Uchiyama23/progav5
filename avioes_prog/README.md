   Baixar e executar o programa 
1)O repositório foi clonado 
git clone https://github.com/Uchiyama23/progav5
2)Abra a pasta clonada chamada progav5 e crie um arquivo de texto chamado .env em avioes_prog
3)Coloque as configurações de seu banco de dados MYSQL no arquivo .env desta maneira (completando as informações): 
MYSQL_USER=
MYSQL_PASSWORD=
MYSQL_PORT=
MYSQL_HOST=
MYSQL_DATABASE=
4)Para começar a rodar no terminal abra a pasta com o comando cd progav5
5)cd avioes_prog
6)uv run avioes.py
